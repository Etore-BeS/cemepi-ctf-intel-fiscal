# Schema — `processos_delta`

**Delta path:** `$LAKE_ROOT/silver_layer/processos_delta`
**Last updated:** 2026-06-25

---

## Overview

Core analytical table. One row per **decision event** within a fiscal execution proceeding scraped from TJSP (Tribunal de Justiça do Estado de São Paulo).

A single process (`cd_processo`) may have multiple rows if it generated multiple decisions across time.

**Scale (2026-06-04):**
- 6,100,561 total rows
- 5,812,126 unique processes
- ~90 GiB on disk (Delta Lake / Parquet)

## Column details

### `id_processo`

Internal integer generated by TJSP's data system. Used by the pipeline for deduplication on `(id_processo, decisao)`. Do **not** use as a public identifier — use `cd_processo` instead.

### `cd_processo`

Official court process number. Format varies:
- CNJ format (post-2009): `NNNNNNN-DD.AAAA.J.TT.OOOO`
- Legacy format: varies by *comarca*

Use this column to join with `face_processos_clean_delta` and `movimentacoes_delta`.

### `data_disponibilizacao`

Date the decision was published in the official court journal. Stored as **text** in `DD/MM/YYYY` format (not as a Date/Datetime column). Parse before date arithmetic:

```python
import polars as pl
df = df.with_columns(
    pl.col("data_disponibilizacao").str.to_date("%d/%m/%Y").alias("data_date")
)
```

### `decisao`

Full text of the decision as published. Can be long (sentence text included). For analysis, consider `tipo_ato` as a pre-extracted act type.

### `tipo_ato`

Act type extracted from the first line of `decisao`. Top values:

| Tipo | Count |
|---|---|
| SENTENÇA P | 4,644,335 |
| SENTENÇA | 375,024 |
| CONCLUSÃO E | 163,009 |
| C O N C L U S Ã O E | 120,346 |
| CONCLUSÃO | 105,334 |

Note: Values like `"C O N C L U S Ã O E"` and `"CONCLUSÃO E"` represent the same act type with formatting noise from the source system. Normalise before analysis.

### `source_bronze_path`

Absolute path to the `process_grouped_all_assuntos.json` file that originated this row. Format: `.../coleta_fazenda_*/process_grouped_all_assuntos.json` or `.../coleta_assunto_*/process_grouped_all_assuntos.json`. Nullable on rows ingested before the `source_bronze_path` column was added; backfill with [`scripts/processos/transforming/backfill_silver_source_paths.py`](../../scripts/processos/transforming/backfill_silver_source_paths.py) (`config.scripts.BACKFILL_SILVER_SOURCE_PATHS`).
